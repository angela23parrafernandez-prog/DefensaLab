# DefensaLab — Guía metodológica para pruebas defensivas

Sitio HTML estático y público, con 24 guías de seguridad web y APIs.

## Publicar en GitHub Pages

1. Subir los archivos a un repositorio público sin secretos ni evidencias reales.
2. En Settings → Pages, elegir Deploy from a branch → main → / (root).
3. Abrir la URL publicada.

## Uso

Abrir `index.html` o navegar a `04-pruebas/NN-.../NN-guia.html`. Cada paso tiene su equivalente de interfaz en inglés en letra secundaria.

## Aviso

Material educativo independiente basado en OWASP ASVS, OWASP WSTG, OWASP API Security Top 10 y NIST SSDF. No es publicación oficial ni certificación. Los procedimientos son ilustrativos, deben adaptarse a la versión de cada herramienta y solo ejecutarse con autorización.


## Actualización: identificación y tratamiento de alertas
Cada guía HTML incluye una matriz de posibles hallazgos, rutas de navegación para localizarlos, correcciones, severidad orientativa y criterios de retest. Son ejemplos para entornos autorizados, no resultados de escaneo reales.


## Cuatro áreas de pruebas
- Aplicaciones web y APIs: 24 procedimientos originales en `04-pruebas/`.
- Servicios: 6 procedimientos en `08-infraestructura/servicios/`.
- Bases de datos: 6 procedimientos en `08-infraestructura/base-datos/`.
- Servidores: 6 procedimientos en `08-infraestructura/servidores/`.

Abrir `index.html` y elegir área. Todas las guías son estáticas y aptas para GitHub Pages.
